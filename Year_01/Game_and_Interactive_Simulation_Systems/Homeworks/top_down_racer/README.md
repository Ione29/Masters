# Top-down Racer - GISS 2025
Simple top-down racing game written in PyGame. Try and get the best lap time!

In order to complete a lap you first have to touch the checkpoint present at the middle of the track.
The checkpoint is red if it was not triggered in that lap, green otherwise.

## Met requirements:
- Collision
- Lap timings
- Sound effects

## Controls:
- WASD / Arrows for controlling the car
